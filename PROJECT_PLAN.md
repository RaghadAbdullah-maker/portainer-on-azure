## Project Plan
Internal Container Management Platform Based on Portainer

## 1. Project Goal
Build an internal container management platform based on Portainer and hosted on Microsoft Azure.

The project will use:
- Terraform for Azure infrastructure provisioning
- Azure Linux VM for hosting
- Docker as the container runtime
- Docker Compose for application deployment
- Portainer for container management
- Bash scripts for deployment and operational automation
- Git and GitHub for version control and team collaboration
  
## 2. Project Phases
Phase 1 - Project Setup

Goal:
Prepare the repository and project documentation before implementation.

Tasks:
- Create GitHub repository
- Add all team members
- Create project folder structure
- Create README.md
- Create .gitignore
- Create project plan
- Create initial architecture documentation
- 
Phase 2 - Azure Infrastructure with Terraform

Goal:
Provision the required Azure infrastructure using Terraform.

Tasks:
-Configure Azure Provider
- Create Resource Group
- Create Virtual Network (VNet)
- Create Subnet
- Create Network Security Group (NSG)
- Configure required NSG rules
